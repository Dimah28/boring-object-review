A deterministic program that writes one funny, true review of the most boring everyday object to `/output/entry.txt`.

> I bought 500 rubber bands. I own three. The rest retired to the junk drawer, where they breed in the dark. They hold papers together. Five stars.

## Run it

```sh
python3 main.py
```

The program writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Python 3.13 standard library only — no network, no randomness, same bytes on every run.
